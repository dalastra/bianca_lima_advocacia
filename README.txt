# Bianca Lima Advocacia Familiarista

Landing page institucional desenvolvida somente com HTML5, CSS3 e JavaScript puro.

## Estrutura

```text
/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    ├── images/
    │   ├── logo.png
    │   ├── bianca.jpg
    │   └── escritorio.jpg
    └── icons/
```

## Configurar WhatsApp

Abra:

```text
js/script.js
```

e altere:

```javascript
const WHATSAPP_NUMBER = "551197428484";
```

O número deve estar no formato internacional, sem espaços, parênteses ou símbolos.

## Imagens

Coloque as imagens reais em:

```text
assets/images/
```

- `bianca.jpg` — foto da advogada
- `escritorio.jpg` — foto do escritório
- `logo.png` — logo/favicon

Enquanto as imagens não forem inseridas, o site mostra placeholders.

## Google Maps

O bloco do mapa está preparado para receber posteriormente um iframe ou link real do Google Maps.

## Instagram e OAB

Não foram adicionados links ou dados fictícios. Insira-os somente quando estiverem confirmados.
